Data Analysis

Telecom Customer Revenue Analytics

This project started with a simple question: how can raw telecom data be transformed into meaningful business insights? The data contained millions of customer and revenue records collected from different operational systems, and it needed significant preparation before any analysis could begin. Duplicate customer records, inconsistent gender values, invalid birth years, and missing information all had to be addressed to ensure reliable results. Using SQL Server, I built a complete data preparation pipeline that imported the raw datasets, validated their quality, cleaned inconsistent records, transformed business attributes, and created a reporting-ready analytical dataset. SQL was then used for exploratory data analysis (EDA) to answer key business questions about customer revenue and behavior. The final stage was an interactive Power BI dashboard that lets users explore revenue trends, compare customer segments, and monitor business performance. Although the dashboard is the final deliverable, most of the work happened before Power BI was even opened, because a reliable analytical dataset was the foundation for accurate insights.

Data Analysis

New York Yellow Taxi Analytics

The New York Yellow Taxi Analytics project is an end-to-end analysis of more than 30 million trip records from 2021, covering trip timing, locations, passengers, distance, fares, payment methods, vendors, and total amounts. The main challenge was not only the dataset’s size, but also making sure the data was reliable enough to support business analysis. Using Google BigQuery and SQL, I started with data profiling: record counts, data types, missing values, distributions, unusual values, and potential duplicates. This revealed several data quality issues that needed investigation. I then created a cleaned analytical layer without modifying the original dataset, and transformed it into an analysis-friendly structure with additional fields for time-based analysis and operational metrics. Exploratory Data Analysis (EDA) then identified meaningful patterns in revenue, trip demand, operating hours, and vendor performance. Finally, the data was connected to Tableau, where an interactive dashboard with KPIs, charts, and filters presents the results around the project’s business questions. Workflow: Big Data → Profiling → Cleaning → Transformation → EDA → Tableau Visualization → Business Insights The project demonstrates how large-scale transportation data can be analyzed systematically while keeping the original data intact and separating data preparation from visualization.

E-Commerce Sales Profitability Analytics

This project analyzes the e-commerce business data to evaluate sales performance and identify the customers, suppliers, geographic segments, and operational factors that have the greatest impact on business performance. The project follows an end-to-end data analytics workflow, starting from raw data profiling and preparation, followed by data cleaning, transformation, dimensional data modeling using a star schema, exploratory data analysis (EDA), and interactive dashboard development using Power BI. The final output is an interactive Power BI dashboard that provides a consolidated view of the business through key performance indicators and visual analysis of sales, customers, suppliers, profitability, and order status.
